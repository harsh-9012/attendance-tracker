# Project Statement - Attendance Tracker

## Problem Statement
Students often struggle to keep track of their attendance across multiple subjects, especially when attendance requirements affect exam eligibility. Manual tracking can be time-consuming and error-prone. This project provides a simple way to record attendance and calculate the attendance percentage for each subject.

## Scope of the Project
This project is a lightweight Python-based attendance tracking prototype. It focuses on adding subjects, recording attendance, calculating attendance percentages, and saving records in a file for reuse. The system is built using modular code so that each part of the project has a clear responsibility.

## Target Users
1. Students who want to monitor attendance in different subjects
2. Faculty or academic staff who need a quick attendance tracking tool
3. Learners practicing Python modular programming and file handling

## Implemented Features
1. Subject management: add subjects with a minimum attendance requirement
2. Attendance recording: mark each class as present or absent
3. Attendance calculation: compute attendance percentage for each subject
4. Report generation: display simple attendance summaries in the console
5. Data storage: save and load attendance data using JSON
6. Logging: store timestamped messages in a log file

## Current Limitations
- No feature for editing or deleting subjects in the current code
- No shortage calculation or eligibility checks
- No visual reports or charts
- No database or secure storage layer
- No user authentication or role-based access
- No user interface or web-based dashboard

## Future Scope
The project can be expanded with subject update/delete operations, shortage calculations, CSV or database storage, better validation, automated tests, and reporting improvements such as charts or saved summaries.
