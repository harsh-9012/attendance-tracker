#Project Statement:- Attendance Tracker

-> Problem Statement
Students often struggle to keep track of their attendance across multiple subjects, especially when attendance requirements affect exam eligibility. Manual tracking is error-prone and time-consuming. This project aims to automate attendance management and provide real-time insights into attendance status.

-> Scope of the Project
The Attendance Tracker system allows students to record, calculate, and analyze attendance data for each subject. It provides features for adding subjects, marking attendance, calculating attendance percentage, and generating reports. The system is designed to be modular, scalable, and easy to maintain.

-> Target Users
1) University and college students who need to monitor attendance.
2) Faculty members who want a simple tool to manage attendance records.
3) Academic administrators who require summarized attendance reports.

-> High-Level Features
1} Subject Management:Add,update and remove subjects.
2} Attendance Recording:Mark attendance for each subject and date.
3} Attendance Calculation:Compute attendance percentage and shortage.
4} Report Generation:Generate summaries and visual reports.
5} Data Storage:Save and retrieve attendance data securely.
6} Logging:Maintain logs for user actions and errors.
7} Testing:Includes unit tests for core calculation logic.
